# ITD Salgsadministration – låst ledelsesdemo v1

**Låst 2. november 2026.** Godkendelses- og præsentationsversion baseret på den reviderede designprototype fra 30. oktober 2026.

- Denne mappe er en uændret, selvstændig kopi af den godkendte brugerflade.
- Formål: Visning for Ledelse, Landechef og Sælger.
- Indeholder fiktive tal og kundedata; **ingen forbindelse til virkelige leads eller WordPress-database**.
- Ændringer til udviklingsversionen i `../design-udspil-2026-10-30/` ændrer ikke denne kopi.
- Skal senere godkendes til fuld WP-produktion før rigtige data bruges.
- Kan indlejres på WordPress-siden `/administration` via pluginet `itd-ledelsesdemo` og shortcoden `[itd_ledelsesdemo]`.

Demoadresse: https://moltrup.github.io/Test/salgsadministration/ledelsesdemo-laast-v1/

GitHub-gren til historisk fastholdelse: `salgsadministration-ledelsesdemo-laast-2026-11-02`.

**Versionsregel:** Uændret indtil ledelsen godkender ændringer. Fremtidig udvikling sker i anden mappe.
