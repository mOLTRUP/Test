ITD SALGSADMINISTRATION – LÅST LEDELSESDEMO, VERSION 1.1.0
=======================================================

Dette er en selvstændig, OFFLINE-FRIGJORT WordPress-præsentation.
Den låste HTML er inkluderet direkte som presentation.html. Der behøves ingen
GitHub-forbindelse for at vise demoen.

INSTALLATION
1. WordPress / Plugins / Tilføj plugin / Upload plugin.
2. Upload ITD_Salgsadministration_Ledelsesdemo_WordPress_OFFLINE_v1.zip
3. Klik Installér nu og Aktivér.
4. Åbn https://www.itd.relogic.dk/administration (eller uden www).

Hvis /administration ikke findes, oprettes en offentlig side automatisk.
Hvis siden findes, bliver den ikke ændret; indsæt [itd_ledelsesdemo] på den.
Hvis du får en 404, gå til Indstillinger / Permalinks / Gem ændringer.

VIGTIGT
- 100 % fiktive demo-data; ingen synkronisering eller databaseopdateringer.
- Sælger, Landechef og Ledelse er demonstrerede VISNINGER, ikke login/roller.
- Alt data indtastet i demoen gemmes kun i browserhukommelsen og forsvinder
  efter genindlæsning.
- Siden er offentlig for enhver med adressen, medmindre du bruger
  WordPress-sidens synlighedsindstillinger.
- Eksisterende side /administration og andet WordPress-indhold overskrives ikke.
- Pluginet fjerner ikke den oprettede side ved deaktivering.
- Installer ikke dette som egentlig salgsadministration med rigtige data.
